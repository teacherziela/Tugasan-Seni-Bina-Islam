HISTORYVERSE 360 — SENI BINA ISLAM
Google Sheet dan folder Drive telah ditetapkan dalam Code.gs.

1. Buka Google Sheet SENI BINA ISLAM > Extensions > Apps Script.
2. Tampal semua kandungan Code.gs, simpan.
3. Jalankan setupDashboard sekali dan benarkan akses Google.
4. Deploy > New deployment > Web app > Execute as Me; access Anyone.
5. Salin URL /exec dan gantikan const SCRIPT_URL='' dalam index.html.
6. Upload index.html ke repository GitHub Pages.
7. Uji satu penghantaran gambar/PDF dan semak tab Penghantaran serta folder Drive.

Nota: Penghantaran belum aktif sehingga Web App Apps Script dideploy dan URL dimasukkan.
